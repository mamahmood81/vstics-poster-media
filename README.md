# vSTICS Poster Media

This repository hosts animated visualizations accompanying the poster:

**“Volumetric Spatio-Temporal Image Correlation Spectroscopy (vSTICS)”**

🔗 **Live site (for QR code):**  
https://mamahmood81.github.io/vstics-poster-media/

---

## Overview

This page provides interactive visualizations of:

- 3D flow fields
- Autocorrelation functions (ACFs)
- Density and diffusion maps
- Experimental imaging of pollen tubes

These animations are intended to complement the static poster by showing the full spatiotemporal dynamics captured by vSTICS.

---

## Organization

### 1. Flow Simulation
- Intensity rendering
- ACF evolution
- Velocity (quiver) field
- Density map

### 2. Diffusion and Flow Simulation
- Intensity rendering
- ACF slices (home, xy, xz)
- Velocity field
- Density map
- Diffusion map

### 3. MitoTracker Green (Mitochondrial Labelling)
- Gaussian / intensity rendering
- Velocity vector field

### 4. FM1-43 (Vesicle Labelling)
- Intensity rendering
- Velocity field
- Density rendering
